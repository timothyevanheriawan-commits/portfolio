# Portfolio

Personal portfolio site showcasing projects and background. Built with a
Swiss-meets-Japanese design system — clean grid structure, restrained type
scale, deliberate motion.

## Stack

- Next.js / React / TypeScript
- Tailwind CSS v4 (CSS-first configuration)
- Framer Motion for page and scroll animation

## Setup

1. **Install dependencies**

npm install


2. **Run the dev server**

npm run dev


   Open <http://localhost:3000>.

## Deployment

Deployed on Vercel: [portofolio-dun-five.vercel.app](https://portofolio-dun-five.vercel.app)
